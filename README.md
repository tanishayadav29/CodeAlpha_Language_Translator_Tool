# 🌍 Language Translator Tool

## 📌 Description
This is a simple AI-based Language Translator web application built using Python and Streamlit. It allows users to translate text between multiple languages and listen to the translated output using text-to-speech.

---

## ✨ Features
- 🌐 Translate text between 10+ languages  
- 📝 Simple and clean UI using Streamlit  
- ⚡ Real-time translation using Google Translator API (deep-translator)  
- 🔊 Text-to-Speech support  
- 📄 Clear output display  

---

## 🛠️ Tech Stack
- Python  
- Streamlit  
- deep-translator  
- gTTS  

---

## 🚀 How to Run

### 1. Clone repository
git clone https://github.com/your-username/language-translator.git  
cd language-translator  

### 2. Create virtual environment
python -m venv venv  

### 3. Activate virtual environment

Windows:
venv\Scripts\activate  

Mac/Linux:
source venv/bin/activate  

### 4. Install dependencies
pip install -r requirements.txt  

### 5. Run application
streamlit run app.py  

---

## 🌐 Supported Languages
English, Hindi, French, Spanish, German, Italian, Portuguese, Russian, Japanese, Korean, Chinese

---

## 🔊 Text-to-Speech
Translated text can be listened to using Google Text-to-Speech (gTTS) directly in the app.
